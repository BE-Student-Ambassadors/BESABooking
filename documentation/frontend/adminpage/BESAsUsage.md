# BESAs Usage

The BESAs page is used to manage student ambassador records.

## Typical Flow

1. Open the BESAs page.
2. Review active/inactive ambassadors.
3. Inspect roles, contact details, and assignment summaries.
4. Update records as staffing changes.

## What This Page Is For

- Keeping the BESA roster current.
- Supporting the booking flow that depends on BESA staffing availability.
