# Tours Management Usage

The Tours page is where admins manage the public tour offerings.

## Typical Flow

1. Open Tours Management from the admin navigation.
2. Review the existing tour list and ordering.
3. Create a new tour or edit an existing one.
4. Configure hours, date rules, buffers, limits, intake form fields, and the Google Calendar destination in Availability.
5. Publish or adjust tours so they appear correctly on the public booking flow.

## Calendar Destination

In the Availability step, choose the Google Calendar ID that should receive this tour's booking invitations. Use `primary` for the OAuth account's primary calendar, or paste the ID for a shared calendar such as Slugworks. The configured Calendar OAuth account must be able to create events in the selected calendar.
