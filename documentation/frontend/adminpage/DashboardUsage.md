# Dashboard Usage

The Dashboard is the starting point for a regular BESA or admin reviewing upcoming activity.

## Typical Flow

1. Open the dashboard after logging in.
2. Review the high-level tour counts for today and this week.
3. Scan the upcoming bookings list.
4. Open a booking to inspect full contact, notes, BESA, and interest details.
5. Edit a booking when date, time, contact, or BESA assignments need adjustment.
6. Refresh BESA assignments after changing date/time, or manually override the suggestion.
7. Delete a booking if it should be removed entirely.

## What This Page Is For

- Quick monitoring of current booking activity.
- Spotting updates, repeated emails, and upcoming tours without opening the full schedule page.
- Performing lightweight booking admin actions directly from the dashboard.

## Environment Behavior

- The page uses the backend admin endpoints for dashboard data, booking edits/deletes, and BESA assignment suggestions.
